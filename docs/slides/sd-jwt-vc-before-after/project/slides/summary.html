一言でいうと

typ（形式の宣言）は IETF 式なのに、中身は W3C 式だった。
中身を IETF 式に並べ直し、typ と揃える。

1

箱を外して、一段目に並べる

氏名・所属などを credentialSubject の箱から出す。他所の検証の道具が、typ どおりの場所で項目を見つけられる。

2

失効を IETF 式でも出す

取り消した会員証を、他所の検証でも弾けるようにする。今は他所では確認が飛ばされていた。

3

本人の署名に名札を付ける

walt.id は名札で本人の鍵を探す。名札が無いと、最初の確認で止まっていた。

変える対象は、選択的開示つきの会員証（ログイン用、dc+sd-jwt）だけ。
