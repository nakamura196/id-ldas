変わる仕組み 2

本人の署名に、鍵の名札を付ける

会員証の中（発行元が署名）

"cnf": { "jwk": {

"kty": "EC", "crv": "P-256",

"x": "…", "y": "…",

"kid": "g_SYTt…" } }

本人の署名（kb+jwt）の見出し

{ "alg": "ES256",

"typ": "kb+jwt",

"kid": "g_SYTt…" }

Before

どちらにも名札が無い。walt.id は「鍵の名前が見つからない」で最初の確認から止まった。

After

両方に同じ名札を入れる。名札は、本人の鍵そのものから計算した指紋（JWK thumbprint）。

名札の値は手元の試験で作った例。本人の鍵はブラウザの中で作られ、外に出ない。

本人の署名は、ログインのたびにブラウザが作る。会員証の写しだけでは通らないようにするための仕組み。
